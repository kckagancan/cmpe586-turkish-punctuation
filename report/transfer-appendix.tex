{\raggedright
\textbf{Reproduction.} \path{scripts/analyze_transfer.py} validates frozen
inputs, runtime/readiness/source bindings, all 52 condition commits and original
targets, then recomputes both-cohort metrics and all paired contrasts from saved
predictions on CPU. \path{scripts/report_transfer_results.py} publishes only
aggregate evidence. The \texttt{--check} option of
\path{scripts/build_transfer_report.py}
verifies the separate paper tables and source binding without raw data or models;
its \texttt{--figures} option redraws the supplemental plot. Original report-table inputs,
tables, figures and run snapshots remain unchanged. No unit suite was run for
this completion audit.
\par}
